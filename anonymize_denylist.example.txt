# EXAMPLE denylist for the insights pass (scripts/insights.py).
#
# insights.py reads fund-internal sources (Notion deal funnel, Gmail weekly
# memos, Fireflies transcripts) and must NEVER let a non-public company,
# founder, or deal term leak into a drafted tweet. This file maps each
# sensitive term to a neutral category label; the drafter substitutes the
# label so the public output stays anonymized.
#
# HOW THE LOADER WORKS
#   insights.py loads your REAL anonymize_denylist.txt if it exists, and falls
#   back to THIS .example file otherwise. So this template just needs valid,
#   parseable lines for the skill to run end-to-end out of the box.
#
# YOUR REAL FILE

#   - Keep it OUT of the repo / share it privately (see SECRETS-TO-SHARE.md).
#
# FORMAT
#   One mapping per line:   <term> -> [<neutral category label>]
#   '#' starts a comment. Blank lines are ignored. Matching is case-insensitive.
